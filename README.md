# SEN-CHA

SENko CHeck tool for Accessibility です。

動画内の明暗・赤色の反復から、目視確認の候補を抽出するローカルアプリです。

**WCAG適合判定や医療上の安全性評価は行いません。** 動画を再生せずに解析し、結果は静止画と時刻で確認できます。必要な場合だけ動画を手動で再生できます。

## 利用する前に

このツールは開発・検証中です。[PEAT（Photosensitive Epilepsy Analysis Tool）](https://trace.umd.edu/photosensitive-epilepsy-analysis-tool-peat-user-guide/)を比較対象の一つとして、同じ動画の結果を突き合わせながら検証を重ねています。PEATと同じ判定方法を実装したものではなく、結果の一致も保証しません。

実際に、比較に使った動画では、PEATが失敗とした区間の一部をこのツールの設定によっては候補にできず、PEATの欠陥表にない区間を候補にした例もあります。現在の検証結果から、見逃しや誤検出の頻度を一般の動画について示すことはできません。比較の条件と結果は[PEATとの比較記録](docs/materials-comparison-2026-09-30.md)を参照してください。

**このツールの結果だけを根拠に、動画が安全である、またはWCAGに適合すると判断しないでください。** 候補がない場合も同様です。利用者自身の責任で、元動画、検出条件、候補の根拠を確認し、必要に応じて別の方法でも評価してください。点滅を含む可能性がある動画の再生には注意してください。

## 起動と使い方

配布アーカイブを展開し、`SEN-CHA`を起動します。
Ubuntuでは専用ウィンドウが開きます。`serve --browser`を指定すると従来のブラウザー画面を使えます。
Windows・macOSは今回実機未検証で、現在の起動方法は既定ブラウザーです。
実行ファイルだけを移動せず、フォルダー全体を保持してください。
PythonとFFmpegは配布物に同梱するため、利用者による追加インストールは不要です。
Ubuntuの専用ウィンドウはOS側のGTK 3、WebKitGTK 4.1、`python3-gi`を利用します。
起動できない場合は`serve --browser`で既定ブラウザーから操作できます。

1. ツールバーの「動画を開く」から端末内の動画を選ぶか、「URLを指定」から公開されたYouTubeの単一動画URLを入力します。
2. 必要に応じて「入力と検出条件」を開き、感度と局所領域の細かさを設定して「解析を開始」を押します。
   初期値の「標準設定」は8×6＋画面全体で候補を広く探します。「低感度（候補を絞る）」で候補が消えても安全・適合は意味しません。
3. 要確認候補の時刻、静止画、領域、検出理由を確認します。
   全体の帯で変化量と候補区間の位置を見つけ、横スクロールできる詳細グラフで時刻を確認できます。広い画面では動画とグラフが横に並びます。候補ボタンや詳細グラフで再生位置を移動でき、位置はグラフ下の時刻スライダーにも反映されます。移動後も動画は一時停止します。
4. ツールバーの「保存」はHTMLを保存します。JSON・CSVは「ファイル」メニューから保存します。
   保存時の既定名は、動画ファイルの名前またはYouTube動画の題名を使い、拡張子を保存形式に合わせます。
5. 「ファイル」メニューの「アプリを終了」を選びます。

画面上部に「ファイル」「表示」「ヘルプ」のメニューがあります。「表示」から入力欄・検出条件・候補一覧を開けます。メニューは上下キーで項目を選び、左右キーでメニューを切り替え、Escで閉じられます。Ctrl+Oで動画を開き、Ctrl+Enterで解析、Ctrl+SでHTMLを保存、Ctrl+Qで終了、F1で使い方を開けます。処理中のCtrl+Qは、処理を中止してから終了します。
「ヘルプ」の「WCAGと検出条件」には、[WCAG 2.3.1の解説書](https://waic.jp/translations/WCAG22/Understanding/three-flashes-or-below-threshold)、[WCAG 2.3.2の解説書](https://waic.jp/translations/WCAG22/Understanding/three-flashes)へのリンクと、このアプリ独自の検出条件を記載しています。
「ヘルプ」の「ライセンス」では本体のMITライセンス原文、第三者ソフトウェア一覧、同梱したライセンス原文を確認できます。

処理中は「中止」が使えます。ブラウザーで開いた場合、タブを閉じただけではアプリは終了しません。
端末から起動した場合はCtrl+Cでも終了できます。
起動時に表示されるURLには操作用トークンが含まれるため、共有しないでください。

## 入力と結果

- 初期版は8ビットSDR動画、4時間以内、画面の各辺8192ピクセル以内が対象です。
- ブラウザーからの入力は4GiB以内。作業領域には動画サイズ＋128MiB以上の空きが必要です。
- MP4/H.264、WebM/VP9を合成動画で検証します。コンテナーはMP4/MOV、WebM/MKV、AVIを許可します。
- YouTube URL入力は`youtube.com`または`youtu.be`の単一動画に限定します。URLを入力して開始したときだけYouTubeへ接続します。
- URL取得はyt-dlpを利用し、720p以下のH.264またはVP9を優先します。動画によっては取得・解析できません。ライブ配信、認証が必要な動画、プレイリストは対象外です。
- YouTubeの配信版はアップロード元ファイルと異なる場合があります。取得した形式・画質での解析結果として読んでください。
- 対応デコーダーは同梱FFmpegの構成に依存します。初期Ubuntu版はH.264、VP9、MPEG-4、FFV1、MJPEG、rawvideo等です。
- HDR、回転メタデータ付き動画、未対応の色域・伝達特性は説明付きで未対応になります。
- 動画の向きは、必要に応じて編集ソフトで確定してから書き出してください。
- 可変フレームレートはフレームの実際の表示時刻を使います。時刻が重複・逆行する動画は扱いません。
- 「今回の検出条件では候補なし」は、適合や安全を意味しません。
- 局所領域は「細かく探す（8×6）」「広い変化を優先（4×3）」「画面全体のみ」から選べます。どの設定でも画面全体を検出します。広い設定ほど局所的な閃光を見逃しやすくなります。
- 解析失敗、中止、未対応は正常完了と区別されます。

HTMLレポートは静止画を埋め込み、ネット接続なしで閲覧できます。
画面とHTMLレポートには明暗・赤色指標のフレーム間変化を時系列で表示します。
画面の全体図と保存HTMLのグラフは最大1200の時間区間に集約し、短い変化の最大値を残します。画面の詳細グラフには、解析時に別途作る最大60000区間のデータを使います。表示区間は横スクロールと全体図のクリック・左右矢印キーで移動できます。
全体図の濃さとグラフの高さは測定した変化量であり、危険度やWCAGの閾値ではありません。
動画の自動再生はしません。動画には強い点滅が含まれる可能性があるため、再生ボタンを押す前に注意してください。再生できる形式はOSとブラウザーのコーデックに依存します。再生できない場合も静止画と候補時刻を確認できます。保存したHTMLレポートには動画や再生機能を含めません。
JSONは設定と詳細な測定値を保存します。CSVは候補の各領域・検出種別ごとに1行を出力します。
完全な条件や制約はHTMLまたはJSONを併せて確認してください。
候補が多い場合の画面表示負荷を抑えるため、解析は1000候補までとし、それを超える入力は失敗として扱います。

## データの扱い

- 端末内の動画ファイルを選んだ場合、動画・結果の外部送信、外部API、CDN、アクセス解析はありません。
- YouTube URLを指定して開始した場合は、その動画の取得に必要な通信を行います。ブラウザーのCookie・認証情報は読み取りません。結果は外部送信しません。
- ブラウザーから選んだ動画は、端末内の専用一時フォルダーへコピーします。
- 元動画は変更しません。一時コピーは正常完了・中止・通常の失敗で削除します。
- URLから取得した動画も端末内の専用一時フォルダーに保存します。解析成功後は画面内での再生用に保持し、次の解析開始時またはアプリ終了時に削除します。中止・通常の失敗時は削除します。
- 再生用動画は推測困難な一時URLからローカルサーバーが配信します。このURLは共有しないでください。
- プロセスの強制終了や電源断では、OSの一時領域に`tvfc-`で始まる作業フォルダーが残る場合があります。
- 保存したレポートには動画の静止画とファイル名が含まれます。共有範囲は元動画と同様に扱ってください。
- URL解析のレポートには取得元URLも含まれます。
- ローカルサーバーは127.0.0.1だけで待ち受け、起動ごとのトークンとHost/Originを検証します。

## 開発環境

Python 3.12以上が必要です。今回の検証用環境はPython 3.13です。
以下はプロジェクトディレクトリで実行する開発者向けの手順です。

```bash
uv venv --python 3.13 .venv
uv pip install --python .venv/bin/python \
  -r requirements-dev.lock
uv pip install --python .venv/bin/python \
  --no-build-isolation --no-deps -e .
```

FFmpegの準備は`docs/distribution.md`を参照してください。
URL取得用QuickJSの準備も同文書を参照してください。

```bash
.venv/bin/sen-cha
```

CLIから解析する場合:

```bash
.venv/bin/sen-cha analyze \
  '/絶対パス/動画.mp4' \
  --region-mode fine \
  --output '/絶対パス/結果フォルダー'
```

```bash
.venv/bin/python -m pytest -q
.venv/bin/python scripts/build.py
```

テスト動画は点滅を含みます。テスト実行は動画を再生しません。
`imageio-ffmpeg`はテスト動画生成専用で、アプリ配布物には含めません。
